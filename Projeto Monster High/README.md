> Projeto Monster High <

Projeto desenvolvido para a disciplina de Desenvolvimento Front-End para Web.

# Sobre o projeto

Este projeto apresenta um site temático sobre Monster High, desenvolvido
utilizando apenas HTML.

O site contém páginas sobre personagens, escola, matérias, eventos,
curiosidades, multimídia, matrícula, quiz e contato.

# Tecnologias utilizadas

- HTML

# Organização

- html/ - páginas HTML
- img/ - imagens
- audio/ - arquivos de áudio
- video/ - arquivos de vídeo
