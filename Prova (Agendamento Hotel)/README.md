> Projeto Agendamento Hotel Velaris <

Projeto desenvolvido para a disciplina de Desenvolvimento Front-End para Web.

# Sobre o projeto

Este projeto apresenta um site de agendamento do Hotel Velaris, desenvolvido
utilizando apenas HTML.

O site contém páginas sobre apresentação do hotel (início), reserva, e cadastro.

# Tecnologias utilizadas

- HTML

# Organização

- html/ - páginas HTML
- img/ - imagens
- audio/ - arquivos de áudio
- video/ - arquivos de vídeo
