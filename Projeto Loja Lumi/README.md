> LUMI – Moda Feminina <

# Sobre o projeto

A LUMI é um projeto de desenvolvimento Front-End que simula uma loja virtual de roupas femininas. O site foi desenvolvido com o objetivo de proporcionar uma experiência de navegação simples, organizada e agradável, permitindo que os usuários explorem diferentes categorias de roupas, visualizem informações dos produtos e naveguem pelas etapas de uma compra on-line.

# Identidade visual

A identidade visual da LUMI utiliza tons de rosa, branco e cores neutras, buscando transmitir delicadeza, elegância e modernidade.

# Estrutura do projeto

- css/ - organização visual
- html/ - páginas HTML
- img/ - imagens

# Tecnologias utilizadas

- HTML: estruturação das páginas e dos formulários.
- CSS: estilização, organização dos elementos e identidade visual
- Visual Studio Code: desenvolvimento e edição do código.
- Git e GitHub: versionamento e armazenamento do projeto.
